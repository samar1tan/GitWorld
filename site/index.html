BRANCHES · STATES · EVIDENCE

Explore history through recorded states.

Follow a historical path, check out a version, and compare what the records say changed. Keep the sources and modeling choices within reach.

The macOS desktop application is in development. The browser workbench is available from source.

Run from sourceRead the requirements ↗
01

Follow a branch

Start with a place and period. Follow the shared Carolingian past into the three outcomes of Verdun, then continue along a successor's path.

history --model gitworld-curated-history --revision <commit-oid> log francia/west --graph
02

Check out a state

Inspect a version's ruler, court residence and recorded territory. See which values were inherited and where each claim was recorded.

history --model gitworld-curated-history --revision <commit-oid> checkout francia/west@843
03

Compare two versions

Compare successive states, sibling branches or independent paths. Equal values, differences and missing evidence remain distinct.

history --model gitworld-curated-history --revision <commit-oid> diff CHECKED francia/east@843

A local workbench

The desktop design keeps exploration, editing and the data library on your machine. New reviewed records enter the same graph and command paths. Core work does not require a public server.

Architecture and data workflow ↗

Evidence with boundaries

The starting records are a selected corpus, not a complete world history. Inherited values are model carry-forward. A citation supports a claim; it does not grant permission to redistribute the source.
